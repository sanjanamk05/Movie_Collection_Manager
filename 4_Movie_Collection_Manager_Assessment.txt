MOVIE COLLECTION MANAGER
AI-ASSISTED SOFTWARE ENGINEERING ASSESSMENT
Duration: 150 Minutes

DEVELOPMENT APPROACH
Use GitHub Copilot, Claude Code, ChatGPT or VS Code Chat. Build the solution primarily through prompting and AI-assisted development.

====================================================
BUSINESS SCENARIO
====================================================
A movie enthusiast has a large personal movie collection containing films from different genres such as Action, Comedy, Drama, Thriller, and Science Fiction.

Managing this collection manually has become difficult. The user wants a simple application to maintain movie details, track ratings, and analyze the collection.

The application should allow users to add movies, browse the collection, identify highly rated movies, and view genre-wise statistics.

You have been hired to develop a Movie Collection Management application.

====================================================
OBJECTIVE
====================================================
Build a Movie Collection Manager application using SQLite database.
